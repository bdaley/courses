Every image on the web is either a **vector** image or a **raster** image. The difference matters because each type has strengths and weaknesses.

## Vector vs. Raster

Think of the difference like this:

- **Vector images** are made of math — lines, curves, and shapes defined by formulas. You can scale a vector image to any size and it stays sharp. Logos, icons, and illustrations are usually vectors.
- **Raster images** are made of pixels — a grid of tiny colored squares. If you zoom in too far, you see the individual pixels. Photographs are always raster.

## Common Raster Formats

| Format | Extension | Best For | Transparency | Animation |
|---|---|---|---|---|
| JPEG | .jpg or .jpeg | Photographs and complex images with many colors | No | No |
| PNG | .png | Images that need transparency (logos, icons, screenshots) | Yes | No |
| GIF | .gif | Simple animations and low-color images | Yes (not alpha) | Yes |
| WebP | .webp | Modern replacement for JPEG and PNG (smaller files) | Yes | Yes |

### JPEG

JPEG is the standard format for photographs. It compresses well, which means small file sizes, but it uses **lossy compression** — some image data is discarded to save space. Every time you save a JPEG, you lose a little quality.

### PNG

PNG uses **lossless compression** — no data is lost. This makes PNG ideal for screenshots, logos, and any image with crisp edges or text. PNG also supports transparency, so you can have a logo with no rectangular background box.

### GIF

GIF is limited to 256 colors, which makes it a poor choice for photographs. But GIF supports simple animations, which is why it is still popular for short looping clips.

### WebP

WebP is a modern format created by Google. It supports both lossy and lossless compression, transparency, and animation — all in a smaller file than JPEG or PNG. Most browsers support WebP, and it is becoming the standard for the web.

## Vector Format: SVG

SVG (Scalable Vector Graphics) is the only vector format used on the web. SVG images are written as XML code, which means they can be created and edited in a text editor.

Advantages of SVG:
- Scales to any size without losing quality
- File sizes are usually very small for simple graphics
- Can be styled with CSS and made interactive with JavaScript
- Individual parts of the image can be targeted and changed
