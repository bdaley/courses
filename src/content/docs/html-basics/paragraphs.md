---
title: Paragraphs
description: Using the paragraph tag in HTML
---

```html
<p>This is a paragraph of text. Browsers will automatically
add space before and after each paragraph element.</p>

<p>Paragraphs can contain multiple sentences. They are
block-level elements, so each paragraph starts on a new line.</p>
```
