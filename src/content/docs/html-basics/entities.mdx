What if you want to display a `<` or `>` symbol on your page? If you type `<` directly, the browser thinks it's the start of an HTML tag. That's where **HTML entities** come in.

An HTML entity is a special code that represents a character. Entities always start with `&` and end with `;`.

## Common HTML Entities

| Character | Entity Code | Description |
|---|---|---|
| `<` | `&lt;` | Less than |
| `>` | `&gt;` | Greater than |
| `&` | `&amp;` | Ampersand |
| `"` | `&quot;` | Double quote |
| `'` | `&apos;` | Apostrophe |
| (non-breaking space) | `&nbsp;` | Space that won't break across lines |
| `©` | `&copy;` | Copyright symbol |
| `™` | `&trade;` | Trademark symbol |
| `®` | `&reg;` | Registered trademark |
