---
title: Line Breaks
description: Using line breaks in HTML
---

```html
<p>This is line one.<br>
This is line two.<br>
This is line three.</p>
```

Use `<br>` (a void element) to break a line inside a paragraph. Avoid using multiple `<br>` tags for spacing — use CSS margins instead.
