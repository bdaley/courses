## What is Responsive Web Design?

**Responsive Web Design (RWD)** is the practice of building a single website that automatically adapts to look good on any screen size — phone, tablet, laptop, or desktop. Instead of building one site for mobile and a different one for desktop, you build one site that responds to the viewer's device.

## Mobile-First Design

When you build a responsive site, you need to decide which screen size to design for first. **Mobile-first** means you start with the mobile layout and then add styles for larger screens as needed.

Think of it like building a house:

- Start with a small, functional room (mobile layout)
- Add walls and expand outward for more space (tablet layout)
- Add even more rooms for the full house (desktop layout)

You never remove anything — you only add.

### Why start with mobile?

1. **Forces focus.** A small screen forces you to prioritize the most important content. Everything else is extra.
2. **Progressive enhancement.** You start with a base that works everywhere and add features for bigger screens. Every device gets a working layout.
3. **The mobile web is huge.** More than half of web traffic comes from mobile devices. Starting with mobile means most visitors get a great experience.

### Mobile-first means `min-width`

In CSS, mobile-first means you write **base styles** for mobile (no media query needed), then use `min-width` media queries to add styles for larger screens. You will see this in the next section.

## Media Queries

A **media query** is a CSS feature that lets you apply styles only when certain conditions are true — like "the screen is at least 768 pixels wide."

Think of it like a responsive light switch: in a small room (mobile), you turn on one lamp (base styles). In a larger room (wider screen), the `@media` rule turns on more lights (additional styles).

### Syntax

```css
/* Base styles apply everywhere — no media query needed */
body {
  background: #f0f0f0;
  font-size: 16px;
}

/* Additional styles apply when viewport is 768px or wider */
@media (min-width: 768px) {
  body {
    background: #e0e0e0;
    font-size: 18px;
  }
}
```

The `@media (min-width: 768px)` rule says: "If the viewport is at least 768px wide, apply these styles on top of the base styles."

### Common breakpoints

You can pick any width you want, but these are common starting points:

| Breakpoint | Typical device |
|---|---|
| 768px | Tablet (portrait) |
| 1024px | Desktop / tablet (landscape) |
| 1200px+ | Large desktop |

Your content should dictate the exact values. As you resize your browser and watch the layout, pick breakpoints where things start to look cramped.

## From Stacked to Multi-Column

Here is the skill you will use most often: **converting a stacked mobile layout into a multi-column layout.**

The pattern is always the same:

1. **On mobile:** Use `flex-direction: column` so items stack vertically.
2. **On wider screens:** Use a media query to switch to `flex-direction: row` so items sit side by side.

### Example: Feature Cards

Here are three feature cards. On mobile they stack. On wider screens they form a three-column row.

<InteractiveCode
  html={`<section class="features">
  <h2>What We Offer</h2>
  <div class="cards">
    <div class="card">
      <h3>Design</h3>
      <p>Clean, modern designs tailored to your brand. We start with wireframes and build up from there.</p>
    </div>
    <div class="card">
      <h3>Development</h3>
      <p>Semantic HTML, modern CSS, and progressive enhancement. Your site works everywhere.</p>
    </div>
    <div class="card">
      <h3>Support</h3>
      <p>Ongoing maintenance and updates so your site stays secure and up to date.</p>
    </div>
  </div>
</section>`}
  css={`* {
  box-sizing: border-box;
}

body {
  font-family: system-ui, sans-serif;
  margin: 20px;
  background: #f8fafc;
}

.features h2 {
  text-align: center;
  margin-bottom: 24px;
  color: #1e293b;
}

/* Mobile: cards stack vertically */
.cards {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

.card {
  background: white;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
  padding: 24px;
}

.card h3 {
  margin-top: 0;
  color: #3b82f6;
}

/* Tablet and wider: cards go side by side */
@media (min-width: 768px) {
  .cards {
    flex-direction: row;
  }

  .card {
    flex: 1;
  }
}`}
/>

Resize the preview. On mobile, the three cards stack in a single column. At 768px and wider, they spread into a three-column row.

Try changing the `768px` in the media query to `500px`. The cards switch to a row layout at a narrower width. What breakpoint feels right to you?

## What You Learned

- Responsive Web Design means one website that adapts to any screen size
- Mobile-first means starting with the mobile layout and adding styles for larger screens using `min-width` media queries
- Media queries (`@media`) let you apply CSS conditionally based on viewport width
- Common breakpoints include 768px (tablet) and 1024px (desktop)
- The core layout pattern: stack items with `flex-direction: column` on mobile, switch to `flex-direction: row` at wider screens
