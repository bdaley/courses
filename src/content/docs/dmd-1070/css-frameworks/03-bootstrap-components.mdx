Beyond the grid, Bootstrap provides dozens of ready-made, accessible **components**. Here are a few you will use often.

## Navbar

A Bootstrap navbar collapses into a hamburger menu on mobile and expands on wider screens — without you writing any JavaScript.

<InteractiveCode
  externalResources={['https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css', 'https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js']}
  html={`<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <title>Bootstrap Navbar</title>
</head>
<body>
  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
      <a class="navbar-brand" href="#">My Site</a>
      <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav">
        <span class="navbar-toggler-icon"></span>
      </button>
      <div class="collapse navbar-collapse" id="navbarNav">
        <ul class="navbar-nav ms-auto">
          <li class="nav-item"><a class="nav-link active" href="#">Home</a></li>
          <li class="nav-item"><a class="nav-link" href="#">About</a></li>
          <li class="nav-item"><a class="nav-link" href="#">Services</a></li>
          <li class="nav-item"><a class="nav-link" href="#">Contact</a></li>
        </ul>
      </div>
    </div>
  </nav>

  <div class="container mt-4">
    <h1>Responsive Navbar</h1>
    <p>Resize the preview to see the navbar collapse into a hamburger menu on small screens.</p>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>`}
/>

The `navbar-expand-lg` class tells Bootstrap: "expand the navbar on large screens and above; collapse it below that." You can use `-md`, `-sm`, or `-xl` to change the breakpoint. Change it to `navbar-expand-md` and see when the collapse happens.

### Key navbar classes

| Class | Purpose |
|---|---|
| `navbar` | Marks the element as a navbar |
| `navbar-expand-*` | Controls the collapse breakpoint |
| `navbar-dark` / `navbar-light` | Text color theme |
| `bg-dark` / `bg-light` | Background color (any Bootstrap bg utility) |
| `navbar-brand` | Your site or logo name |
| `navbar-toggler` | The hamburger button (mobile only) |
| `navbar-collapse` | The collapsible wrapper for nav links |
| `nav-item` / `nav-link` | Individual navigation entries |

### Key card classes

| Class | Purpose |
|---|---|
| `card` | Marks the element as a card |
| `card-body` | Main content area with padding |

| `card-header` / `card-footer` | Optional top and bottom sections |

## Buttons and Alerts

Bootstrap includes utility classes for common UI elements that you can use anywhere on your page.

## What You Learned

- A **CSS framework** is a pre-built toolkit providing a grid system, components, and consistent styling
- **Bootstrap** is the most popular CSS framework, but many others exist (Foundation, Bulma, Tailwind)
- You add Bootstrap to a page using a **CDN link** in the `<head>`
- Bootstrap's **grid** uses a container → row → column structure with 12 columns and mobile-first breakpoints
- Column classes like `col-md-6` combine a breakpoint prefix and a column count
- Combining breakpoints (`col-12 col-md-6 col-lg-4`) creates different layouts at different screen sizes
- Bootstrap components like **navbars**, **cards**, **buttons**, and **alerts** provide ready-made, responsive UI elements
