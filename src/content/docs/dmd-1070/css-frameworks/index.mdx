## What Are CSS Frameworks?

So far you have built every layout from scratch — writing your own HTML structure, creating your own CSS classes, and writing media queries for responsive breakpoints. This is a great way to learn, but professional web designers rarely start from absolute zero on every project.

A **CSS framework** is a pre-written collection of CSS (and often JavaScript) that gives you:

- A ready-made **responsive grid system**
- Pre-styled **components** (buttons, navbars, cards, forms)
- **Consistent spacing and typography** across your site
- Cross-browser compatibility

Think of a CSS framework like moving into a furnished apartment instead of building a house from scratch. The furniture is already there — you just rearrange it to fit your style.

## Why Use a CSS Framework?

Learning to build layouts from scratch taught you *how* CSS works. Now that you understand the fundamentals, a framework helps you build faster:

1. **Speed** — you write less CSS because the framework handles the heavy lifting
2. **Responsive by default** — the grid system handles breakpoints for you
3. **Consistency** — components look the same across all pages
4. **Battle-tested** — frameworks work across all major browsers
5. **Community** — huge communities mean plenty of tutorials, templates, and support

The trade-off: your site may look similar to other sites using the same framework unless you customize it. You will learn how to customize Bootstrap later in the course.

## Popular CSS Frameworks

There are many CSS frameworks available. They all share core ideas but have different styles and approaches:

- **Bootstrap** — the most widely used framework. Huge library of components, excellent documentation.
- **Foundation** — a professional-grade framework with a focus on accessibility.
- **Bulma** — a lighter, modern framework based on Flexbox.
- **Tailwind CSS** — a utility-first framework that gives you small building-block classes.

For this course we will focus on **Bootstrap**, but the concepts you learn — especially the responsive grid — apply to almost any CSS framework.
