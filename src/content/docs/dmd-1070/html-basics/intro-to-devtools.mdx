Every modern web browser includes **Developer Tools** — a set of built-in tools that let you inspect, debug, and experiment with your web pages.

## Opening DevTools

- **Chrome/Edge:** Right-click anywhere on a page and select "Inspect," or press `Ctrl+Shift+I` (Windows/Linux) or `Cmd+Option+I` (Mac)
- **Firefox:** Right-click and select "Inspect Element," or press `Ctrl+Shift+I`

## The Elements Panel

The Elements panel shows your page's HTML structure. You can:

- See the HTML and CSS for any element
- Edit HTML and CSS in real time (changes are temporary)
- See box model dimensions
- Check accessibility properties

Try it yourself: open DevTools on any website, click the Elements tab, and hover over different HTML elements. Watch how they highlight on the page.
