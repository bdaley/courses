All web pages must be validated before submitting to HuskyCT. The process of validation will help you attain a deeper understanding of HTML. It can also catch potential errors that may cause rendering problems in certain web browsers.

## Common HTML Errors

- **Missing closing tags** — forgetting `</p>`, `</li>`, or `</a>`
- **Nesting mistakes** — overlapping elements like `<p><strong>text</p></strong>`
- **Missing required attributes** — like `alt` on `<img>` or `href` on `<a>`
- **Incorrect doctype** — missing or outdated `<!DOCTYPE html>`
- **Duplicate IDs** — using the same `id` value on multiple elements

## How to Validate

1. Go to the [W3C Markup Validator](https://validator.w3.org/)
2. Choose the **Validate by Direct Input** tab
3. Copy and paste your HTML code
4. Click "Check"
5. Read the errors and fix them

The following video demonstrates HTML Validation through the "Direct Input" method. However, I highly recommend uploading your pages to the DMD web server and validating through the "URI" method.
