## Block Elements

Block elements start on a new line and take up the full available width. They create a "block" of content:

- `<p>` — paragraphs
- `<h1>` through `<h6>` — headings
- `<div>` — generic container
- `<ul>`, `<ol>` — lists
- `<hr>` — horizontal rule

## Inline Elements

Inline elements flow within the text. They only take up as much space as needed:

- `<strong>` — important text (bold)
- `<em>` — emphasized text (italic)
- `<a>` — links
- `<span>` — generic inline container
- `<img>` — images
- `<br>` — line breaks
