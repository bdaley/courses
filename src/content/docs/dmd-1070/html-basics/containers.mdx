Sometimes you need to group elements together without changing their meaning. That's where generic containers come in.

## The `<div>` Element (Block Container)

`<div>` is a block-level container with no built-in styling or meaning. It's a "blank box" you use to group content together, often so you can style or layout them as a unit.

<InteractiveCode
  css={`.card {
  border: 1px solid #ccc;
  padding: 16px;
  border-radius: 8px;
  background: #f9f9f9;
}
.card-title {
  font-size: 1.25rem;
  margin: 0 0 8px;
}`}
  html={`<div class="card">
  <h2 class="card-title">About Us</h2>
  <p>We are a small team of designers.</p>
  <p>This entire card is styled as one group using a div.</p>
</div>`}
/>

Try adding more content inside the `<div class="card">` — it will automatically be grouped inside the card.

## The `<span>` Element (Inline Container)

`<span>` is the inline version of `<div>`. It wraps a piece of text or inline content without breaking the line. Use it when you want to style a portion of text differently.

<InteractiveCode
  css={`.highlight {
  background: #ffeb3b;
  padding: 2px 4px;
}
.price {
  color: #e53935;
  font-weight: bold;
}`}
  html={`<p>You can use <span class="highlight">span</span> to style parts of a sentence.</p>
<p>Today's special: <span class="price">$9.99</span></p>`}
/>
