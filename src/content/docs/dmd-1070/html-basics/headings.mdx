## Heading Hierarchy

HTML provides six heading levels, `<h1>` through `<h6>`. Think of them like an outline:

- `<h1>` — the page title (use only one per page)
- `<h2>` — major sections
- `<h3>` — sub-sections within an `<h2>` section
- And so on down to `<h6>`

**Never skip levels.** Going from `<h2>` to `<h4>` confuses screen readers and creates a poor outline. If you need a smaller heading, use CSS to style it — don't jump levels.

## Accessibility & Headings

Screen reader users often navigate a page by jumping from heading to heading. A well-structured outline (with no skipped levels and a single `<h1>`) helps everyone understand your page's organization.
