Every modern web browser includes **Developer Tools** — a set of built-in tools that let you inspect, debug, and experiment with your web pages.

Think of DevTools as your website's X-ray machine. HTML and CSS can sometimes behave in unexpected ways, and DevTools lets you look inside your page to see what's really happening.

## What You Can Do with DevTools

- **Inspect HTML** — see the full structure of your page, edit text and attributes live
- **Debug CSS** — see which styles apply to any element, test changes instantly, and understand why a rule isn't working
- **Visualize layouts** — see the box model, flexbox axes, and alignment at a glance
- **Test responsive designs** — preview your page at different screen sizes without leaving the browser
