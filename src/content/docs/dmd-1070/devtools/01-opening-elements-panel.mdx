## Opening DevTools

There are several ways to open DevTools:

- **Right-click** anywhere on a page and select **Inspect** (or **Inspect Element** in Firefox)
- **Keyboard shortcuts:**

| Browser | Windows / Linux | Mac |
|---|---|---|
| Chrome / Edge | `Ctrl+Shift+I` | `Cmd+Option+I` |
| Firefox | `Ctrl+Shift+I` | `Cmd+Option+I` |
| Safari | — | `Cmd+Option+I` |

Try it now: right-click anywhere on this page and choose **Inspect**.

## The Elements Panel

When DevTools opens, you will usually land on the **Elements** panel (called **Inspector** in Firefox). This panel shows your page's HTML structure as a tree of elements.

### Selecting Elements

Move your mouse over different lines in the Elements panel. As you hover, the corresponding element highlights on the page. Click any line to select it — that element's styles appear in the Styles panel to the right.

You can also use the **element picker** — the cursor-with-a-box icon in the top-left corner of DevTools. Click it, then click any element on the page. DevTools automatically selects that element in the HTML tree.

### Editing HTML Live

You can edit any element's HTML directly in the Elements panel:

- **Edit text:** Double-click the text inside an element and type to change it
- **Edit attributes:** Double-click an attribute value (like `class="card"`) and change it
- **Delete an element:** Right-click an element and choose **Delete Element**
- **Add an attribute:** Right-click an element and choose **Add Attribute**
- **Copy HTML:** Right-click and choose **Copy** → **Copy OuterHTML**

All changes are **temporary** — they disappear when you refresh the page. This makes DevTools a safe space to experiment without breaking your files.
