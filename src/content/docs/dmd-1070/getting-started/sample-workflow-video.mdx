FTP is for publishing, not previewing. This demo shows the day-to-day loop: edit in VS Code, preview with a local server (Live Server), then upload only when ready.

**You will learn**

* Why you should not rely on FTP to test changes
* Opening a folder as a local site and launching Live Server
* Saving, refreshing, and iterating quickly
