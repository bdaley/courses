Although any editor works, demos use VS Code (`code.visualstudio.com`). After this video you will be able to install VS Code, invoke the Command Palette, and scaffold an HTML page with Emmet (`!` + Tab).

**Checklist after watching**

* [ ] VS Code installed and side-bar explorer familiar
* [ ] `Cmd/Ctrl+Shift+P` opens Command Palette
* [ ] Emmet snippet `!` creates a full `html:5` boilerplate
