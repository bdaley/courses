Two equal columns side by side is the most basic Flexbox layout. A single `display: flex` on the container and `flex: 1` on each column is all it takes.

<InteractiveCode
  html={`<div class="container">
  <div class="column">Left Column</div>
  <div class="column">Right Column</div>
</div>`}
  css={`.container {
  display: flex;
  gap: 20px;
}

.column {
  flex: 1;              /* Each column takes equal width */
  padding: 20px;
  background: #f4f4f4;
}`}
/>

Try changing the `gap` value or adding a third column (`<div class="column">Center</div>`).
