`flex-basis` sets the starting size of a flex item before extra space is distributed. `flex-grow` controls how much of the remaining space an item should take up.

<InteractiveCode
  html={`<div class="flex-container">
  <div class="item-fixed">Fixed 200px</div>
  <div class="item-stretch">Grows to fill space</div>
</div>

<div class="flex-container" style="margin-top: 20px;">
  <div class="item-sidebar">Sidebar 250px</div>
  <div class="item-main">Main (grows)</div>
</div>`}
  css={`.flex-container {
  display: flex;
}

.item-fixed {
  flex-grow: 0;
  flex-basis: 200px;
  background: #666;
  color: white;
  padding: 15px;
}

.item-stretch {
  flex-grow: 1;
  flex-basis: 0;
  background: steelblue;
  color: white;
  padding: 15px;
}

.item-sidebar {
  flex: 0 0 250px;
  background: #666;
  color: white;
  padding: 15px;
}

.item-main {
  flex: 1 1 auto;
  background: steelblue;
  color: white;
  padding: 15px;
}`}
/>

Try changing `flex-grow: 0` to `flex-grow: 1` on `.item-fixed` — it starts growing too. Try changing `flex: 0 0 250px` to `flex: 0 0 150px` on the sidebar.
