**CSS Grid is awesome!** However, in this course we're going to focus on using Flexbox for our layouts. Since you're just starting out, we'd rather have you master one important layout technique before moving on to something like CSS Grid. We typically cover CSS Grid in Web II.

Here is how to think about the difference:

- **Flexbox** — great for one-dimensional layouts (rows OR columns). Think navigation bars, card rows, side-by-side content.
- **CSS Grid** — great for two-dimensional layouts (rows AND columns at the same time). Think full-page layouts with headers, sidebars, main content, and footers all defined in one container.

Flexbox can handle most layouts you will build in this course. Master Flexbox first, then explore Grid.

With that said, if you can't wait for Web II, feel free to check out the excellent resources below.

- [Grid by Example](https://gridbyexample.com/)
- [Learn CSS Grid](https://learncssgrid.com/)
