Typography is one of the most visible things CSS controls. The right font choices can completely change how a website feels.

## Font Family

The `font-family` property sets which typeface to use:

```css
p {
  font-family: Arial, sans-serif;
}
```

You provide a **fallback stack** — a comma-separated list. The browser tries the first font, and if it's not available, moves to the next.

**Generic families** go at the end as a last resort:

| Generic family | Examples | Look |
|---|---|---|
| `serif` | Times New Roman, Georgia | Small lines (serifs) at letter ends |
| `sans-serif` | Arial, Helvetica, Verdana | Clean, no serifs |
| `monospace` | Courier New, Consolas | All letters same width |

```css
/* Good font stacks */
body {
  font-family: Georgia, serif;
}

code {
  font-family: 'Courier New', monospace;
}
```

## Font Size

The `font-size` property controls how big text appears:

```css
h1 {
  font-size: 32px;
}

p {
  font-size: 16px;
}
```

(We'll cover different units like `px`, `em`, and `rem` in the [CSS Units](05-units/) section.)

## Font Weight

The `font-weight` property controls how **bold** text is:

```css
strong {
  font-weight: bold;  /* or 700 */
}

.light-text {
  font-weight: 300;   /* lighter than normal */
}
```

Common values: `normal` (400), `bold` (700). You can also use numbers from 100 to 900.

## Font Style

The `font-style` property controls italics:

```css
em {
  font-style: italic;
}
```

## Line Height

The `line-height` property controls the space *between* lines of text:

```css
p {
  line-height: 1.6;  /* 1.6 times the font size */
}
```

A value of `1.6` is good for readability in long paragraphs. A value of `1` would make lines touch.

## Text Alignment

The `text-align` property controls horizontal alignment:

```css
h1 {
  text-align: center;
}
```

| Value | Effect |
|---|---|
| `left` | Aligned to the left (default) |
| `center` | Centered |
| `right` | Aligned to the right |
| `justify` | Stretched to fill the full width |

## Text Decoration

The `text-decoration` property adds lines to text:

```css
a {
  text-decoration: none;  /* removes underline from links */
}

.strikethrough {
  text-decoration: line-through;
}
```

## Using Google Fonts

Your computer only has certain fonts installed. To use a wider variety, you can import fonts from Google Fonts.

1. Go to [fonts.google.com](https://fonts.google.com/)
2. Pick a font and click "Get font"
3. Copy the `<link>` tag Google provides
4. Paste it in your HTML `<head>`
5. Use the font name in your CSS `font-family`

```html
<head>
  <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">
  <style>
    body {
      font-family: 'Roboto', sans-serif;
    }
  </style>
</head>
```
