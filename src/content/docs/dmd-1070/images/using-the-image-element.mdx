The `<img>` element adds an image to an HTML page. It is a **void element** — it has no closing tag and no content of its own.

<InteractiveCode
  html={`<!-- Basic image with required src and alt attributes -->
<img src="photo.jpg" alt="A sunset over the ocean">

<!-- Image with width and height -->
<img src="logo.png" alt="Company logo" width="200" height="100">

<!-- Image as a link -->
<a href="https://example.com">
  <img src="banner.jpg" alt="Click to visit our site">
</a>`}
/>

## The `src` Attribute

The `src` (source) attribute tells the browser where to find the image file. The value is a URL — either a relative path or an absolute URL.

- **Relative path**: Points to a file within your own site, e.g. `images/photo.jpg`
- **Absolute URL**: Points to a file on another site, e.g. `https://example.com/images/photo.jpg`

For your own projects, always use relative paths.

## The `alt` Attribute

The `alt` (alternative text) attribute provides a text description of the image. It is **required** for accessibility.

Screen readers read the alt text aloud so that people who cannot see the image still understand its content. Alt text also appears on the page when the image fails to load.

Good alt text describes the content and purpose of the image. For a photo of a team, write `alt="Our marketing team at the annual retreat"` — not `alt="team"` or `alt="IMG_0423.jpg"`.

### Functional images, decorative images, and complex images

- **Functional images** (logos, buttons, icons): the alt text should say in words what the image says visually. A company banner gets `alt="Acme Carpet Cleaners"`, not `alt="banner"`. An icon button gets `alt="Play"` or `alt="Print"`.
- **Decorative-only images** (a flourish that adds no information): use an empty alt attribute, `alt=""`. This hides the graphic from screen readers instead of announcing a meaningless filename.
- **Complex images** (charts, diagrams): alt text alone is not enough. Pair the image with a visible `<figcaption>` caption and, for data charts, an accessible data table so screen-reader users get the same information.

## The `width` and `height` Attributes

The `width` and `height` attributes tell the browser how much space the image needs. Setting them helps the browser reserve space before the image loads, which prevents the page layout from jumping around.

These values are in pixels. You do not write `px` — just the number: `width="300"`.

## Image Display Characteristics

Images display as **inline** elements by default. This means they sit on the same line as surrounding text, like a large character. Unlike most inline elements, images do have a height and width that you can set.

## Making Images Clickable

To make an image into a link, wrap the `<img>` element inside an `<a>` element.

<LinkCard title="Making Images Clickable" href="/courses/dmd-1070/images/making-images-clickable-video/" description="Watch on dedicated video page." />

<InteractiveCode
  html={`<!-- A clickable image -->
<a href="https://example.com/gallery">
  <img src="gallery-thumb.jpg"
       alt="Open the photo gallery"
       width="200" height="150">
</a>`}
/>

Try changing the width and height. Notice how the image size changes but the link still works.

## The `loading` Attribute

The `loading="lazy"` attribute tells the browser to wait to load the image until it is about to appear on the screen. This makes the page load faster, especially on pages with many images.

```html
<img src="photo.jpg" alt="A mountain view" loading="lazy">
```

## A Note on the Picture Element

HTML also has a `<picture>` element for art direction and responsive image formats. It is beyond the scope of this course — stick with `<img>` for now.

## Figure and Figcaption

The `<figure>` element wraps an image together with a caption. The `<figcaption>` element holds the caption text.

```html
<figure>
  <img src="office.jpg" alt="Our open-plan office space">
  <figcaption>Our team works in a collaborative open-plan office.</figcaption>
</figure>
```

Using `<figure>` and `<figcaption>` helps search engines and assistive technology understand that the caption belongs to the image.
