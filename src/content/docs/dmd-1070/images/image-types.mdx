Every image on the web is either a **vector** image or a **raster** image. The difference matters because each type has strengths and weaknesses.

## Vector vs. Raster

Think of the difference like this:

- **Vector images** are made of math — lines, curves, and shapes defined by formulas. You can scale a vector image to any size and it stays sharp. Logos, icons, and illustrations are usually vectors.
- **Raster images** are made of pixels — a grid of tiny colored squares. If you zoom in too far, you see the individual pixels. Photographs are always raster.

## Common Raster Formats

| Format | Extension | Best For | Transparency | Animation |
|---|---|---|---|---|
| JPEG | .jpg or .jpeg | Photographs and complex images with many colors | No | No |
| PNG | .png | Images that need transparency (logos, icons, screenshots) | Yes | No |
| GIF | .gif | Simple animations and low-color images | Yes (not alpha) | Yes |
| WebP | .webp | Modern replacement for JPEG and PNG (smaller files) | Yes | Yes |

### JPEG

JPEG is the standard format for photographs. It compresses well, which means small file sizes, but it uses **lossy compression** — some image data is discarded to save space. Every time you save a JPEG, you lose a little quality.

JPEG images are full-color (24-bit, up to 16.8 million colors) and let you slide between higher quality and smaller files. Pushing compression too far creates visible blockiness and "noise," especially around text and sharp edges. A variant called **progressive JPEG** loads in gradually from blurry to sharp, giving visitors a preview while the file downloads.

### PNG

PNG uses **lossless compression** — no data is lost. This makes PNG ideal for screenshots, logos, and any image with crisp edges or text. PNG also supports transparency, so you can have a logo with no rectangular background box.

PNG shines on line art, text, and logos — images with large areas of flat color and sharp transitions. For photographs it works but produces much larger files than JPEG, so prefer JPEG or WebP for photos. PNG files can also embed a short text description of the image content, which search engines can use to index the image.

### GIF

GIF is limited to 256 colors, which makes it a poor choice for photographs. But GIF supports simple animations, which is why it is still popular for short looping clips.

Because GIF uses lossless LZW compression, it compresses best when there are large areas of flat color — logos and diagrams, not photos. Saving with fewer colors (for example 16 or 32 instead of the full 256) can shrink the file substantially with no visible difference on simple graphics.

> Based on Patrick J. Lynch and Sarah Horton, *Web Style Guide*, Chapter 11 Images — [webstyleguide.com/11-images.html](https://webstyleguide.com/11-images.html). Licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

### WebP

WebP is a modern format created by Google. It supports both lossy and lossless compression, transparency, and animation — all in a smaller file than JPEG or PNG. Most browsers support WebP, and it is becoming the standard for the web.

## How to Choose: Test and Compare

There is no magic formula like "always use JPEG for this, always use PNG for that." Use this beginner workflow:

1. Guess based on the image: photo → JPEG/WebP, crisp logo or screenshot → PNG/SVG, simple animation → GIF/WebP.
2. Export the same image in two formats and compare file size and quality side by side.
3. Pick the smallest file that still looks good — especially for larger images where the savings add up.

Small graphics can fool you: a tiny hard-edged icon "should" be a GIF, but sometimes a PNG or JPEG is smaller or sharper. Testing beats guessing.

## Sometimes the Best Graphic Is No Image File

Buttons, color fields, rules, shadows, and simple icons often do not need an image file at all. They can be built with CSS styling or with inline SVG/icon fonts, which scale cleanly and cost almost nothing to download. Before exporting a graphic, ask: "Could CSS do this instead?"

## Vector Format: SVG

SVG (Scalable Vector Graphics) is the only vector format used on the web. SVG images are written as XML code, which means they can be created and edited in a text editor.

Advantages of SVG:
- Scales to any size without losing quality
- File sizes are usually very small for simple graphics
- Can be styled with CSS and made interactive with JavaScript
- Individual parts of the image can be targeted and changed

</svg>`}
/>

Try changing the house color or adding a chimney. Every part of an SVG is editable code.
