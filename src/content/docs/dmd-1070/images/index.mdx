Images make the web interesting. Without images, web pages would be nothing but plain text. Images help you communicate ideas, show products, set a mood, and guide a visitor's attention.

But images also come with challenges. A large, unoptimized photo can make your page load slowly. The wrong file format can look blurry or have a large file size. An image without a text description can be invisible to someone using a screen reader.

In this section you will learn:

- The difference between image file types and when to use each
- How to organize image files in your project
- How to add images to your HTML pages
- How to resize and optimize images for the web

## Why Images? Branding vs. Content

Not all images do the same job. It helps to sort them into two roles:

- **Interface and branding images** — logos, icons, buttons, background textures. Kept consistent across pages, they signal "you are still on this site." A collection of bare pages with no shared graphics does not feel like a cohesive site.
- **Content images** — images that carry meaning alongside your text:
  - **Illustrations:** show things from the world (a product, a place, a team)
  - **Diagrams:** explain a process or how parts fit together
  - **Quantitative charts:** make numbers visual (spending over time, survey results)
  - **Analysis and causality:** take a topic apart or show what caused what
  - **Integration:** combine words, numbers, and images into one explanation
