Images make the web interesting. Without images, web pages would be nothing but plain text. Images help you communicate ideas, show products, set a mood, and guide a visitor's attention.

But images also come with challenges. A large, unoptimized photo can make your page load slowly. The wrong file format can look blurry or have a large file size. An image without a text description can be invisible to someone using a screen reader.

In this section you will learn:

- The difference between image file types and when to use each
- How to organize image files in your project
- How to add images to your HTML pages
- How to resize and optimize images for the web
