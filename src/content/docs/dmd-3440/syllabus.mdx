## Course Description

**DMD 3440 — Introduction to Mobile Application Development. (3 Credits)**

Through lecture and hands-on exercises, students will be introduced to the processes, technologies, and environment of mobile applications.

**Enrollment Requirements:** DMD 1060 and 1070; open only to Digital Media and Design majors, others with instructor consent.

DMD 5440 is the graduate section of this course. Graduate students complete the same core curriculum with expanded expectations on the final project and AI development journal.

## What You'll Build

By the end of the semester you'll design and develop a complete mobile application using **React Native** and **Expo** that demonstrates:

- User-centered design principles
- Effective mobile UX/UI design
- Multi-screen navigation
- Data management and persistence
- API integration and/or device capabilities
- Accessibility considerations
- Appropriate use of AI-assisted development tools
- Professional documentation and presentation skills

## Tools & Environment

- **Node.js** — the JavaScript runtime that powers Expo. Install from [nodejs.org](https://nodejs.org/)
- **Expo** — the framework we use to build and test our React Native apps. Start with the [Expo docs](https://docs.expo.dev/get-started/start-developing/)
- **Expo Go** — a free app that lets you run your project on your own phone for testing
- **VS Code** — the code editor recommended for this course
- **Figma** — used for wireframes and interactive prototypes
- **GitHub** — for version control and project submission

## Course Structure

### Unit 1: Foundations (Weeks 1–5)

Mobile app development fundamentals, React Native basics, user-centered design, prototyping, and application architecture.

### Unit 2: Building Applications (Weeks 6–10)

Practical skills in AI-assisted development, state management, persistence, APIs, and device integrations — while you begin implementing your final project.

### Unit 3: Refinement and Professional Practice (Weeks 11–14)

Final project development alongside accessibility, testing, deployment, and presentation practices common to professional mobile app development.
