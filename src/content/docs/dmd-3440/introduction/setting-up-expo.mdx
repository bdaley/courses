This lab gets your **development environment** running and puts your first Expo app on a screen. By the end you'll have a personalized profile app running on your phone, an emulator, or the web.

## What You Need

- **Node.js** (a recent LTS version) — the JavaScript runtime that powers Expo. Install from [nodejs.org](https://nodejs.org/)
- **VS Code** — your code editor
- **Expo Go** — a free app from the App Store or Google Play that runs Expo projects on your phone

## Create Your First App

Open a terminal and run:

```bash
npx create-expo-app@latest my-profile-app
cd my-profile-app
npx expo start
```

`npx expo start` launches the Expo development server. From here you can:

- Scan the QR code with **Expo Go** on your phone to run the app on a real device
- Press `w` to open it in your web browser
- Press `a` (Android) or `i` (iOS) to run it in an emulator

:::note
Not sure whether to test in Expo Go or a development build? Expo has a helpful video and guide on the difference.
:::

## Understand the Project Structure

A new Expo project has a few key files. Find them in your project:

- **`app/`** — your screens (with Expo Router, each file becomes a screen). You'll work here all semester
- **`package.json`** — the list of libraries your project depends on
- **`app.json`** — Expo configuration for your app (name, icon, splash screen)

## Lab: Customize a Personal Profile App

Your task is to make the starter app yours. Customize it into a simple **personal profile** screen. In the main screen file, change:

1. The greeting text to your name
2. Add a line describing your major or interests
3. Change the background color or text styling
4. Add at least one more element — an image, a second line of text, or a button

Try editing the styles in the `StyleSheet.create` block to see how styling changes in real time with **fast refresh**. Save the file and the app updates instantly.
