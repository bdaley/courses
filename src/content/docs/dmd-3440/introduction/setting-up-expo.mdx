This lab gets your **development environment** running and puts your first Expo app on a screen. By the end you'll have a basic **"Hello World"** app running in an emulator/simulator or web browser.

## What You Need

- **Node.js** (a recent LTS version) — the JavaScript runtime that powers Expo. Install from [nodejs.org](https://nodejs.org/)
- **VS Code** — your code editor

## Create Your First App

Open a terminal and run:

```bash
npx create-expo-app@latest my-hello-world-app
cd my-hello-world-app
npx expo start
```

`npx expo start` launches the Expo development server. From here you can:

- Press `w` to open it in your web browser
- Press `a` (Android) or `i` (iOS) to run it in an emulator/simulator

:::caution[Windows PowerShell: `npm` cannot be loaded / `npm.ps1` blocked]
If `npm run web` (or `npx expo start`) fails on Windows with an error like `cannot be loaded because running scripts is disabled on this system` or referencing `npm.ps1`, this is Windows PowerShell blocking the `npm.ps1` shim — not a problem in your Expo app.

**1. Confirm the policy** — in PowerShell run:

```powershell
Get-ExecutionPolicy -List
```

If `CurrentUser` or `LocalMachine` shows `Restricted`, PowerShell is blocking local scripts.

**2. Temporary fix — current terminal only** (least invasive):

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm run web
```

This allows scripts only in this terminal session and resets when you close it.

**3. Persistent fix — your Windows user account** (recommended for the semester):

Open PowerShell normally (not as Administrator) and run:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Confirm with `Y`, then restart your terminal and run `npm run web` again. `RemoteSigned` allows locally installed scripts like npm while still requiring downloaded scripts to be signed — it is scoped to your user account only (no admin) and does not change the system-wide `LocalMachine` policy.

> Alternative: you can also use **Command Prompt (`cmd.exe`)** instead of PowerShell, which is not affected by this policy.
:::

## Understand the Project Structure

A new Expo project has a few key files. Find them in your project:

- **`app/`** — your screens (with Expo Router, each file becomes a screen). You'll work here all semester
- **`package.json`** — the list of libraries your project depends on
- **`app.json`** — Expo configuration for your app (name, icon, splash screen)

## Lab: Build a Basic App using Expo/React Native

Your task is to create a simple mobile app that displays **"Hello World"** on the screen.

1. Open the main screen file (e.g., `app/index.tsx` or `app/(tabs)/index.tsx` depending on the template).
2. Ensure the screen renders the text `Hello World`. For example:

   ```tsx
   import { Text, View } from 'react-native';

   export default function Index() {
     return (
       <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
         <Text>Hello World</Text>
       </View>
     );
   }
   ```

3. You may style it however you like, but the core functionality — displaying "Hello World" — must be present.

Try editing the styles in the `StyleSheet.create` block to see how styling changes in real time with **fast refresh**. Save the file and the app updates instantly.
