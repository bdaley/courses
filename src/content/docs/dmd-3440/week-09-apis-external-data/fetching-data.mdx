Time to actually fetch. React Native provides the **`fetch`** API — the same one browsers use — plus a few React patterns that make network code clean.

## The Basic Fetch

```jsx
const response = await fetch('https://pokeapi.co/api/v2/pokemon/pikachu');
const data = await response.json();
console.log(data.name); // "pikachu"
```

Two things happen:

1. `fetch(url)` sends the request and returns a **response**
2. `response.json()` parses the JSON body into a JavaScript object

But there's a catch: `fetch` **doesn't throw an error on a bad HTTP status** (like 404). You must check `response.ok` yourself:

```jsx
const response = await fetch(url);

if (!response.ok) {
  throw new Error(`Request failed: ${response.status}`);
}

const data = await response.json();
```

## Async Workflows — Fetch on Mount

Combine `useEffect` + `useState` to load data when a screen appears (from [Week 7](../week-07-state-management/use-state-and-effects/)):

```jsx
const [pokemon, setPokemon] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

useEffect(() => {
  async function load() {
    try {
      const response = await fetch('https://pokeapi.co/api/v2/pokemon/pikachu');
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      const data = await response.json();
      setPokemon(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }
  load();
}, []);
```

The three states now map to three branches in your UI:

```jsx
if (loading) return <ActivityIndicator size="large" />;
if (error) return <ErrorState message={error} onRetry={reload} />;
return <PokemonDetails pokemon={pokemon} />;
```

## Error and Loading States Done Right

A professional error state tells the user what happened and how to recover:

- **Message** — "Couldn't reach the server. Check your connection."
- **Action** — a Retry button that re-runs the fetch
- **No blank screens** — every state has a visible UI

Set up the retry by wrapping the load logic in a function you can call again:

```jsx
const [attempt, setAttempt] = useState(0);

useEffect(() => {
  // ... fetch code, depends on `attempt`
}, [attempt]);

// Retry button
<Button title="Retry" onPress={() => setAttempt((a) => a + 1)} />
```

## Empty States

A successful fetch can still return **no data**. Handle it explicitly:

```jsx
if (data.length === 0) {
  return <EmptyState message="No results found" />;
}
```

An empty list with no message looks broken. An empty state with an icon and a friendly line looks designed.

## Lists of Data

For lists of results, pair fetch with `FlatList`:

```jsx
<FlatList
  data={data}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => <PokemonRow name={item.name} />}
/>
```

Each item renders through `renderItem`, keeping even long lists fast and smooth.
