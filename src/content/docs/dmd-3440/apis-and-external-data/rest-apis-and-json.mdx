Before fetching, let's understand the protocol: what a **REST API** is and what **JSON** looks like.

## REST APIs

**REST** (Representational State Transfer) is a style of web API organized around **resources** (things like routes, movies, users) and **endpoints** (URLs).

A common pattern: the server hosts URLs, and clients request them.

| Endpoint | What it does |
|---|---|
| `GET /routes` | List all routes |
| `GET /routes/12` | Get one route |
| `GET /routes/12/stops` | Get stops for that route |

The key method for this course is **GET** — fetch data. (POST, PUT, DELETE create, update, and remove, but most of your final project will be reading.)

The server responds with a **status code**:

- `200 OK` — success
- `404 Not Found` — the resource doesn't exist
- `500 Internal Server Error` — the server failed

Your app checks the status to decide whether the request succeeded.

[MDN: REST glossary](https://developer.mozilla.org/en-US/docs/Glossary/REST)

## JSON — The Data Format

**JSON** (JavaScript Object Notation) is how most APIs return data. It's just text that looks exactly like JavaScript objects and arrays:

```json
{
  "id": 12,
  "name": "Farmington Ave",
  "arrival": "5:42 PM",
  "isFavorite": false
}
```

Two things to remember in React Native:

1. **It arrives as a string** — you parse it with `JSON.parse` (or the fetch API does it for you)
2. **Keys are strings** — access fields with dot notation: `data.name`

## Find a Public API

Hundreds of free, keyless APIs are available for practice. A good one for this course is the [PokéAPI](https://pokeapi.co/) (free, no key, no rate limits for classroom use) — or browse the [public APIs list](https://github.com/public-apis/public-apis).

Try requesting one in your browser first so you can see the raw response:

```
https://pokeapi.co/api/v2/pokemon/pikachu
```

You'll see JSON with stats, types, and more. That's exactly what your app will fetch and display.

[PokéAPI](https://pokeapi.co/)
