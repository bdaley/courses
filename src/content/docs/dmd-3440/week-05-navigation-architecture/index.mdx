## Organizing Application Structure

A well-organized project is one where you can always find the code you're looking for. Expo's file-based router gives you a natural structure: **each screen is a file in the `app/` directory**.

A small project might look like:

```
my-profile-app/
  app/
    index.tsx          # Home screen
    routes.tsx         # Routes list
    settings.tsx       # Settings
  components/
    RouteCard.tsx
    TabBar.tsx
  constants/
    colors.ts
```

Notice two ideas:

- **Screens** live in `app/`; **reusable components** live in `components/`
- Related screens group together, and shared values (like colors) get their own file

## Planning Scalable Projects

Your final project is small, but real apps are not. A few habits keep projects scalable from day one:

1. **One component per file** — each file does one thing and has a clear name
2. **Share the repeated stuff** — common styles, colors, and components in dedicated files
3. **Name files after what they contain** — a file called `RouteCard.tsx` obviously contains the route card component
4. **Keep screens thin** — screens compose components rather than containing thousands of lines
