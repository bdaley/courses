## Overview

Across the semester you'll design and develop a mobile application using **React Native** and **Expo**. The exercises across the course build toward this project, so by the time you reach the final presentation most of the work is already done.

Your app should demonstrate:

- User-centered design principles
- Effective mobile UX/UI design
- Multi-screen navigation
- Data management and persistence
- API integration and/or device capabilities
- Accessibility considerations
- Appropriate use of AI-assisted development tools
- Professional documentation and presentation skills

## Project Milestones

### Progress Check #1

A working prototype with navigation and persistent data. You'll demo the app in class and get instructor feedback before continuing.

### Progress Check #2

An accessibility review of your project plus a revision plan. See [Accessibility & Inclusive Design](../accessibility/) for the full checklist.

### User Testing

Peer testing sessions with a brief user testing report. See [Testing & User Feedback](../testing-and-user-feedback/) for the format.
