Photos are the most common native feature in mobile apps. Expo provides **`expo-camera`** (capture) and **`expo-image-picker`** (camera capture *and* library picking). For most use cases, ImagePicker is the simpler and more flexible choice.

## Install

```bash
npx expo install expo-camera expo-image-picker
```

## Picking from the Photo Library

The simplest approach — let the user pick an existing photo:

```jsx
import * as ImagePicker from 'expo-image-picker';

async function pickImage() {
  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ['images'],
    allowsEditing: true,
    quality: 1,
  });

  if (!result.canceled) {
    setImage(result.assets[0].uri);
  }
}
```

Two things to notice:

- `result.canceled` — the user can back out; always check before using the result
- `result.assets[0].uri` — the local file URI of the picked image, which you can pass straight to an `<Image>` component

## Taking a Photo with the Camera

To capture with the camera, first **request permission**, then launch the camera:

```jsx
import * as ImagePicker from 'expo-image-picker';

async function takePhoto() {
  const { status } = await ImagePicker.requestCameraPermissionsAsync();

  if (status !== 'granted') {
    setError('Camera access is needed to take photos.');
    return;
  }

  const result = await ImagePicker.launchCameraAsync({ quality: 1 });

  if (!result.canceled) {
    setImage(result.assets[0].uri);
  }
}
```

Note the flow: **request permission → check status → handle denial → capture**. That's the responsible permission pattern from this unit's main page.

## Display the Image

Once you have a URI, render it with the `Image` component:

```jsx
<Image source={{ uri: image }} style={{ width: 200, height: 200 }} />
```

Local files use `source={{ uri }}` — the same form you'd use for any URL.
