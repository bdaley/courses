CSS — Cascading Style Sheets — is the language that controls how HTML looks.

Think of it this way: HTML is the **structure** of a house (walls, roof, rooms). CSS is the **paint, wallpaper, furniture, and lighting** — everything that makes it look good.

## CSS Syntax

Every CSS rule follows the same pattern:

```css
selector {
  property: value;
}
```

| Part | Meaning | Example |
|---|---|---|
| **Selector** | Which HTML element(s) to style | `p` selects all `<p>` elements |
| **Property** | What aspect to change | `color` controls text color |
| **Value** | How to change it | `red` makes the text red |

## Three Ways to Add CSS

There are three places you can write CSS. Each has a different use.

### 1. External CSS — Best for real websites

Write CSS in a separate `.css` file and link it in your HTML `<head>`:

```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```

**Why this is best:** One CSS file can style many pages. Change one file, update your whole site.

### 2. Internal CSS — Good for single-page experiments

Write CSS inside a `<style>` tag in your HTML `<head>`:

```html
<head>
  <style>
    p { color: navy; }
  </style>
</head>
```

Useful for testing, but not for multi-page sites.

### 3. Inline CSS — Avoid for most things

Write CSS directly on an HTML element using the `style` attribute:

```html
<p style="color: navy;">This text is navy.</p>
```

This works, but it mixes content with presentation. If you want to change the color of every paragraph, you'd have to edit each one individually.

## Comments in CSS

Use `/*` and `*/` to add notes that won't affect the output:

```css
/* This is a comment. Browsers ignore it. */
p {
  color: gray; /* Comments can go inline too */
}
```
