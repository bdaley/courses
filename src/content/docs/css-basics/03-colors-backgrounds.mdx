Two of the most common things you'll do with CSS are changing text color and adding background colors or images.

## Text Color: The `color` Property

The `color` property changes the color of text. You can specify colors in several ways.

### Named Colors

CSS recognizes 140 named colors like `red`, `blue`, `green`, `navy`, `firebrick`, and `rebeccapurple`:

```css
p {
  color: navy;
}
```

### Hex Codes

A **hex code** (short for hexadecimal) is a six-character code starting with `#`. It lets you pick from over 16 million colors:

```css
p {
  color: #2c3e50;
}
```

- `#ff0000` = red, `#00ff00` = green, `#0000ff` = blue
- Pairs stand for Red, Green, Blue: `#RRGGBB`
- `#000000` = black, `#ffffff` = white

Tools like the [Adobe Color wheel](https://color.adobe.com/) or your browser's DevTools color picker can help you find hex codes.

### rgb()

The `rgb()` function lets you specify red, green, and blue values from 0 to 255:

```css
p {
  color: rgb(44, 62, 80); /* same as #2c3e50 */
}
```

## Background Color: The `background-color` Property

Sets the background color of any element:

```css
.box {
  background-color: #f1c40f;
}
```

  css={`.card {

## Background Images: The `background-image` Property

You can use an image as a background instead of a solid color:

```css
.banner {
  background-image: url("banner.jpg");
}
```

The `url()` function points to the image file, just like the `src` attribute in HTML images.

### Background Size

The `background-size` property controls how the image fits:

```css
.banner {
  background-image: url("banner.jpg");
  background-size: cover;  /* Scales to fill the element, may crop */
}
```

| Value | What it does |
|---|---|
| `cover` | Scales image to cover the whole area (may crop edges) |
| `contain` | Scales image to fit entirely inside (may leave empty space) |
| `100% 100%` | Stretches image to fill exactly (may distort) |

### Avoiding Image Repetition

By default, background images repeat (tile) to fill the space. You can control this:

```css
.banner {
  background-image: url("pattern.png");
  background-repeat: no-repeat;   /* Show image once */
  /* or */
  background-repeat: repeat-x;    /* Repeat horizontally only */
  /* or */
  background-repeat: repeat-y;    /* Repeat vertically only */
}
```
