Most of the basics will be covered by your assignments in HuskyCT. However, these videos highlight some of the most important or most often misunderstood aspects of using CSS.

## Example

```css
/* Element selector */
p {
  color: #333;
  font-size: 16px;
}

/* Class selector */
.highlight {
  background-color: yellow;
  font-weight: bold;
}

/* ID selector */
#logo {
  width: 200px;
  border: none;
}
```

## CSS Reference

In the following videos, you'll see a few basic CSS properties used, but there are so many more available. Tympanus has a great reference resource for CSS properties and instructions for their use.

When I teach this class in person, I usually tell students that they'll need to memorize every CSS property on this page for an upcoming quiz. That joke doesn't work as well online. But please click through some of the properties on this website. You don't need to memorize them all. Just try to take inventory of what is possible. You can always Google something like "[CSS background blending](https://www.google.com/search?q=CSS+background+blending)" to determine the correct syntax to use.
