Every major browser vendor supplies some form of "DevTools" within their browser. In fact, once you learn your way around one, it's fairly easy to use the Developer Tools that are provided by other browsers.

The following video highlights some of the more useful features for debugging CSS within the Chrome web browser. I would urge you to keep your DevTools open and follow along with the demos.
