## The CDN Approach

The easiest way to add Bootstrap to a project is via a **CDN** (Content Delivery Network) — a link that loads the framework files from a fast, global server. You do not need to download anything or install any software.

You need two things:

1. **Bootstrap CSS** — loads all the styles (grid, components, utilities)
2. **Bootstrap JavaScript** — enables interactive components (navbars, modals, carousels)

## The Bootstrap Boilerplate

Here is a minimal HTML page that includes Bootstrap:

<InteractiveCode
  externalResources={['https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css']}
  html={`<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <title>My Bootstrap Page</title>
</head>
<body>
  <div class="container mt-4">
    <h1>Hello, Bootstrap!</h1>
    <p>This page includes Bootstrap via CDN. The <code>container</code> class adds responsive horizontal padding.</p>
    <button class="btn btn-primary">A Bootstrap Button</button>
  </div>
</body>
</html>`}
/>

Try adding a second button with the class `btn btn-success` to see how easy it is to add styled elements without writing any CSS.

### Key details

- The `<link>` tag in the `<head>` loads Bootstrap's CSS from the CDN
- The `viewport` meta tag is already there from responsive design — Bootstrap needs it to work correctly
- For interactive components (like a collapsing navbar), you also need the JavaScript bundle at the bottom of the page
